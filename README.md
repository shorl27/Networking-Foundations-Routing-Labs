# 🌐 Networking Foundations & Security Labs

A hands-on networking and cybersecurity laboratory portfolio built using **Cisco Packet Tracer**.

This repository documents my progression from fundamental Layer 2 and Layer 3 networking into practical network security.

Rather than only following configuration tutorials, I use the labs to build networks, test communication, intentionally introduce failures, troubleshoot them, and implement security controls.

> **Build → Test → Break → Troubleshoot → Secure → Verify**

---

# 🎯 Objectives

The primary goals of this portfolio are to develop practical understanding of:

- IPv4 addressing and subnetting
- Ethernet and MAC addresses
- ARP
- Switching
- VLANs
- 802.1Q trunking
- Routing
- Default gateways
- Routing tables
- Inter-VLAN routing
- NAT and PAT
- Access Control Lists
- Network segmentation
- DMZ architecture
- TCP/IP
- ICMP
- Network troubleshooting
- Traffic analysis
- Network security principles

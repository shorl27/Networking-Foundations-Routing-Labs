# 🌐 Networking Foundations & Security Labs

A hands-on cybersecurity and networking laboratory portfolio developed using Cisco Packet Tracer.

This repository documents my progression from fundamental networking concepts into practical network security, including VLAN segmentation, routing, NAT/PAT, ACLs, DMZ architecture, and traffic analysis.

The labs are designed around a practical workflow:

> Build → Configure → Test → Break → Troubleshoot → Secure → Verify

---

# 🎯 Project Objective

The goal of this repository is to develop practical understanding of how computer networks operate and how they can be secured.

The projects cover:

- IPv4 addressing
- Subnetting
- Switching
- VLANs
- Trunking
- Routing
- Inter-VLAN routing
- Router-on-a-Stick
- NAT
- PAT
- Access Control Lists
- Network segmentation
- DMZ architecture
- Least-privilege network security
- TCP/IP
- ICMP
- Network troubleshooting
- Traffic analysis
